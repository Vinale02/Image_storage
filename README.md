# Image storage (FastAPI & PostgreSQL)

Веб-приложение на базе **FastAPI** и **PostgreSQL** для загрузки, просмотра и удаления изображений. Проект включает в себя логику валидации файлов, логирования, а также инструменты для резервного копирования базы данных.

---

## Технологический стек

* **Backend:** Python, FastAPI, Uvicorn
* **Шаблонизатор & Стили:** Jinja2, HTML5, CSS
* **База данных:** PostgreSQL
* **Логирование:** Встроенный модуль 'logging'

---

## Запуск

Проект полностью упаковывается в Docker-контейнеры и запускается с помощью **Docker compose**. Исключением является скрипт для создания бэкапов базы данных.

1. **Соберите Docker-образы:**
   ```bash
   docker compose build
   ```
2. **Запустите контейнеры:**
   ```bash
   docker compose up -d
   ```

После успешного запуска сервисы будут доступны по следующим адресам:

1. Веб-приложение (FastAPI / Nginx): http://localhost
2. PgAdmin (Управление БД): http://localhost:5050


**Для остановки контейнеров выполните:**
   ```bash
   docker compose down
   ```

## Основные маршруты

* `GET /` — Главная страница сервиса.
* `GET /images/` — Страница галереи с поддержкой пагинации (`?page=1`).
* `GET /upload/` — Страница формы загрузки изображений.
* `POST /upload/` — Обработка загрузки файла (проверка формата, ограничения размера, сохранение на диск и запись метаданных в базу данных).
* `GET /delete/{id}` — Удаление изображения с диска и из базы данных с последующим редиректом на галерею.

## Резервное копирование и восстановление базы данных

Для управления бэкапами базы данных PostgreSQL в корне проекта предусмотрен скрипт `backup.sh`.

**1. Создание резервной копии**

Запустите скрипт из корневой папки проекта:
```bash
./backup.sh
```
Файлы сохраняются в папку `backups/` в формате: `backup_YYYY-MM-DD_HHMMSS.sql`.

**2. Восстановление базы данных**

Для восстановления базы данных из конкретного файла бэкапа выполните команду:
```bash
docker exec -i image_storage-postgres-1 psql -U postgres image_storage < backups/<имя_файла_бэкапа>.sql
```
*(Пример: `docker exec -i postgres psql -U postgres image_storage < backups/backup_2025-01-24_153000.sql`)*
